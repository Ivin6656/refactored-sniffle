# NeuroGrip — Healthcare Portal Demo

A professional, minimal front-end prototype for the NeuroGrip rehabilitation project.

## Included
- Separate Patient and Medical Team login portals
- Two fictional patient profiles
- Patient dashboard with:
  - health/vital snapshot
  - rehabilitation metrics
  - functional recovery profile
  - medical history
  - exercise plan
  - care guidance
  - medical assistance/contact flow
- Medical Team dashboard with:
  - patient list
  - searchable patient records
  - patient profile view
  - functional metrics
  - medical history and vitals
  - clinical analytics
  - ability to add advice to a patient
- Responsive layout for desktop/tablet/mobile
- Local browser storage for demo medical advice
- No external backend and no real patient data

## Run
Open `index.html` in a modern browser.

This is a front-end demonstration only. The records are fictional and the authentication is not secure enough for real healthcare deployment. A production system would require a secure backend, encrypted transport/storage, real identity/access management, audit logging, consent controls, clinical validation, and applicable healthcare/privacy compliance.
